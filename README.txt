NEXORA WEBSITE

Структура:
index.html              — страница сайта
styles.css              — стили
app.js                  — интерактивность
assets/                 — локальные ресурсы
assets/nexora-mark.svg  — favicon/знак Nexora
downloads/              — сюда положить установщик

Установщик должен называться:
Nexora-Setup.exe

После этого ссылка:
./downloads/Nexora-Setup.exe
будет скачивать установщик.

Сайт статический: отдельный backend для скачивания не нужен.
